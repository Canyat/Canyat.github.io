# 1. Analyse the Task

**Keyword** --> **Analyse the question** --> **Plan the paragraphs**

<font color="grey"># 审题，从关键词到分析问题，最后安排段落内容开始行文</font>

# 2.Plan the Paragraphs

: Decide the conclusion

<font color="grey"># 先定结论，也就是把中心论点点出来</font>

: How many paragraphs

<font color="grey"># 要分多少段，提前规划</font>

: Main idea

<font color="grey"># 分段后要把每一段写什么，确定好</font>

# 3. Body paragraphs

**One paragraph - One main point**

<font color="grey"># 每一个段落，最多写一个要点，这才能做到观点明确结构清晰</font>

## Structure

<font color="grey"># 文章结构大体如下</font>

Introduction（引言）

**B.P 1: Topic Sentence + viewpoint** 

**B.P 2: Topic Sentence + viewpoint** 

**B.P 3: Topic Sentence + viewpoint** 

......

Conclusion（结论）

# 4. Conclusion

: I strongly agree that ......

: Both of the views expressed in the question are correct.
