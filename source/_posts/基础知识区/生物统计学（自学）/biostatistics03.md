# t检验

## 前提

1. 数据是独立的
2. 数据是连续型
3. 样本数据是从总体中随机抽样的
4. 存在方差齐性（各组数据变异性相似）
5. 分布接近正态分布

## 类型

### 1. 单样本t检验

----**确认总体均值是否为某特定值**

<font color="grey"># 一组人员平均心率是否为65</font>

df = n - 1

### 2. 双样本t检验

----**确认两个不同组的总体均值是否相等**

<font color="grey"># 两组人员平均心率是否相同</font>

df = n1 + n2 - 2

### 3. 成对（配对）t检验

----**确定某个总体的成对测量值之间的差异是否为0**

<font color="grey"># 一组人员锻炼前后心率平均差异是否为0</font>

df = n - 1

## t值的使用

### 一般情况

以 **t 0.05, 21 = 2.080** 为例 <font color="grey"># 这个t值可以说是临界值</font>

**0.05** 即 **α = 0.05**          <font color="grey"># 95%的置信水平</font>

**21** 即 **21个自由度**  <font color="grey"># 需要根据实际应用去算</font>

**若统计量 ＞ t      则拒绝原假设H0**

### **用软件的情况**

软件输出

- Prob > | t |        value
- Prob > t            value
- Prob < t            value

则直接用P值的方法去检验

小于0.05or0.01则否定原假设，反之亦然
